# Aura Agent

**Identity mirror repository**

This repository exists as a public identity and discovery surface for **Aura**, the perception and content agent in the Saphira AI multi-agent system.

> **Source of truth:** [chichi-lyman/saphira-ai](https://github.com/chichi-lyman/saphira-ai)

All active development lives in the monorepo. This repository is intentionally lightweight.

## Role in the Pipeline

```
Saphira → Aura → Agent Two → Nova Reign → NovaAethrea → Agent Zero
```

Aura handles perception, entity context, face recognition, UI/content generation, and multimodal understanding.
