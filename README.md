## Overview
Aura is the perimeter defense specialist for the Nova Umbrella network. Operating quietly in the background, Aura monitors local logs, cloud nodes, and network traffic to safeguard sensitive information and detect security anomalies in real time.

- **Stealth Monitoring:** Low-overhead background process evaluation.
